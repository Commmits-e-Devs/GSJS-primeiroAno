# GSJS – Primeiro Ano

Repositório de exercícios e práticas desenvolvidas no primeiro ano com foco em fundamentos de desenvolvimento web utilizando HTML, CSS e JavaScript.

---

## Descrição

Projeto acadêmico voltado ao estudo inicial de lógica de programação, estruturação de interfaces web e manipulação do DOM.
O conteúdo reúne atividades realizadas ao longo do período letivo.

---

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)
